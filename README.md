## 📐 Overview & Layout Architecture

This project uses a clean, centered box layout for maximum clarity and quick interaction:

| Section | Key Features & Functionality |
| :--- | :--- |
| **Header Canvas** | Bold title display with custom playful typography |
| **Control Box** | Side-by-side interactive buttons (`+` and `-`) with active press effects |
| **Counter Display** | Center display box showing real-time numerical count update |

---

## ✨ Features

* ⚡ **Instant Response:** Direct DOM updates upon button clicks.
* 🎨 **Playful Styling:** Aesthetic color palette featuring dynamic active-state drop shadows.
* 📱 **Centered Layout:** Flexbox-powered responsive design centered for all screen sizes.
